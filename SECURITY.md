# Security Policy

## Supported Versions

We release security updates only for the latest stable version of MagmaKey.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

> The latest version is always available in the [Releases](https://github.com/MrKhaimi/MagmaKey/releases/latest) section.

## Reporting a Vulnerability

If you discover a vulnerability in MagmaKey, please report it responsibly.

### How to report

- **Do NOT create a public Issue** describing the vulnerability — this may put other users at risk.
- Send an email to **matveiyt2006@gmail.com** with the subject `[SECURITY] MagmaKey vulnerability`.
- Or use the [Security → Report a vulnerability](https://github.com/MrKhaimi/MagmaKey/security/advisories/new) tab on GitHub.

### What to include

1. Version of MagmaKey where the vulnerability was found.
2. Detailed description of the issue.
3. Steps to reproduce (if possible).
4. Potential impact.
5. Your contact info (optional).

### What to expect

- **Confirmation of receipt** — within 72 hours.
- **Initial assessment** — within 7 days.
- **Fix** — depending on complexity, usually within 14–30 days.
- **Public credit** — if you wish, we will mention you as the researcher who found the vulnerability (after the fix is released).

### If the vulnerability is accepted

We will release a patch and publish a notice in the Releases section. You will be credited (if you agree).

### If the vulnerability is declined

We will explain the reason and, if needed, provide recommendations.

Thank you for helping keep MagmaKey secure! 🔐

# Политика безопасности

## Поддерживаемые версии

Обновления безопасности выпускаются только для актуальной стабильной версии MagmaKey.

| Версия  | Поддерживается     |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

> Актуальную версию всегда можно найти в разделе [Releases](https://github.com/MrKhaimi/MagmaKey/releases/latest).

## Сообщение об уязвимости

Если вы обнаружили уязвимость в MagmaKey, пожалуйста, сообщите о ней ответственно.

### Как сообщить

- **НЕ создавайте публичный Issue** с описанием уязвимости — это может подвергнуть риску других пользователей.
- Отправьте письмо на **matveiyt2006@gmail.com** с темой `[SECURITY] MagmaKey vulnerability`.
- Либо используйте вкладку [Security → Report a vulnerability](https://github.com/MrKhaimi/MagmaKey/security/advisories/new) на GitHub.

### Что указать в отчёте

1. Версия MagmaKey, в которой обнаружена уязвимость.
2. Подробное описание проблемы.
3. Шаги для воспроизведения (если возможно).
4. Возможное влияние уязвимости.
5. Ваши контактные данные (по желанию).

### Что вы можете ожидать

- **Подтверждение получения** — в течение 72 часов.
- **Первичная оценка** — в течение 7 дней.
- **Исправление** — в зависимости от сложности, обычно в течение 14–30 дней.
- **Публичное упоминание** — если вы захотите, мы укажем вас как исследователя (после выпуска исправления).

### Если уязвимость принята

Мы выпустим патч и опубликуем уведомление в разделе Releases. Вы будете упомянуты в благодарностях (если не против).

### Если уязвимость отклонена

Мы объясним причину отказа и, при необходимости, дадим рекомендации.

Спасибо за помощь в обеспечении безопасности MagmaKey! 🔐
